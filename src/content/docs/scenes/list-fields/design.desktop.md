# 定位

`eds-biz-list-fields` 记录了常见字段类型在表格中的展示规则，适用于所有业务场景

# 币种

- **优先原则**：无特需，确保数据完整性
- **显示**：币种 Logo、代币符号（如 BTC）、网络名称（示例：`USDT-Ethereum`）
- **主网**：如果是当前网络的主网代币，显示币种 Logo、代币符号（示例：`ETH`）
- **跨链**：如果是主网代币但在其他网络，显示币种 Logo、代币符号、网络名称（示例：`ETH-Tron`）
- **组合**：仅支持币种与地址组合使用
   - 仅币种：字段只有币种信息
   - 币种与单地址：币种信息+单地址。此时地址应该遵循“地址-优先原则”
   - 币种与双地址：币种信息+双地址。此时地址应该遵循“地址-显示原则”

# 地址

- **优先原则**：无特需，确保数据完整性
- **单地址** 
   - 显示：完整展示，溢出时中间省略如：`bc1qmakjy7ns2z8vwgpt...f9vs8fndp304fg0p9xafm2`
   - 悬浮：数据完整时无悬浮交互，省略时使用 `Tooltip` 展示完整数据
   - 复制：悬浮至 `Data List` 行时，显示复制， `Tooltip` 里也有复制
   - 地址合集：使用 `（N）` 展示，悬浮时使用 `Tooltip` 展示完整数据
   - 预置变体：别名、Tag（ `System Tag` 、`Colorful Tag` ）

- **双地址** 
   - 显示：默认省略中间部分（如 `bc1qma...9xafm2`）
   - 悬浮：使用 `Tooltip` 展示完整数据
   - 复制：`Tooltip` 里显示复制 Icon
   - 地址合集：使用 `（N）` 展示，悬浮时使用 `Tooltip` 展示完整数据
   - 预置变体：别名、Tag（ `System Tag` 、`Colorful Tag` ）

- **挂件**：详情 `Detail` 时展示 `复制`

# 金额

- **法币：**
    - 排序：按金额升序、按金额降序
    - 分隔符：支持千分位分隔符（如 `66,666.66`）
    - 精度：按币种精度展示小数点后两位
    - 金额为0：显示为 `$0`  示例：`$10`、`$1.1`、`$0`
- **加密货币：**
    - 分隔符：支持千分位分隔符（如 `66,666.6666`）
    - 显示极限：百亿级（如 `88,888,888,888.888888888888888888`）
    - 精度：做统一处理（待定）
        
        
        | 币种 | 实际精度 | 展示精度 |
        | --- | --- | --- |
        | BTC | `18` | `6` |
        | ETH | `18` | `8` |
        |  |  |  |
    - 汇率：实时汇率折合（如适用），格式：`数量 币种 ≈ 折合法币金额` 示例：`12,500.000001 USDT ≈ $12,500.01`

# 时间

- 排序：按时间顺序、按时间逆序
- 格式：`YYYY-MM-DD HH:MM:SS`
- 时区：默认使用本地时区
- UTC 偏移量：表头显示 UTC 偏移量（示例：`交易时间（UTC+08:00）`）
